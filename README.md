# Sistema de Chamados

Aplicacao web local para a escola, com acesso por navegador, banco PostgreSQL e anexos salvos em volume Docker.

## Como rodar

1. Se quiser, copie `.env.example` para `.env`.
2. Suba os containers com Docker Compose.
3. A aplicacao executa as migracoes ao subir o container web.
4. Entre no Django admin ou crie o primeiro usuario de administracao.
